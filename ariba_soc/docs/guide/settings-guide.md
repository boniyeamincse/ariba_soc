# Settings Guide

## Overview
The Ariba SOC platform features a centralized Settings layout accessible from the top navbar. 

## Key Configuration Areas
- **User Management:** Create, edit, and disable user accounts.
- **Role & Permission:** Define granular access controls for different analyst tiers.
- **Analyst Profile:** Manage avatars, teams, and designations.
- **Wazuh API Settings:** Configure the SIEM integration endpoint.
- **Alert Source Settings:** Register new log sources (e.g., Firewalls, EDR).
- **Severity Settings:** Customize severity labels and colors.
- **Status Settings:** Define workflow states (New, In Progress, Closed).
- **Verdict Settings:** Define outcomes (True Positive, False Positive).
- **SLA Settings:** Set countdown timers for alert response based on severity.
- **Escalation Settings:** Build automated rules for routing specific alerts.
- **Notification Settings:** Configure email/webhook alerts.
- **Audit Log Settings:** Toggle which platform actions are logged for compliance.
