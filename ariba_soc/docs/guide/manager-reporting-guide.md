# Manager Reporting Guide

## Overview
SOC Managers rely on accurate metrics to assess team performance and platform health. Ariba SOC provides built-in dashboard analytics and exportable reports.

## 1. The Dashboard
The main Dashboard provides real-time KPIs:
- **Total Alerts vs Active Alerts**
- **Critical Incidents**
- **SLA Breach Warnings**

## 2. Generating Reports
Navigate to the **Reports** tab.
- Select your date range.
- Filter by Severity, Status, or Assignee.
- Click **Export PDF** for executive summaries.
- Click **Export CSV** for raw data analysis in Excel/Tableau.

## 3. SLA Monitoring
Navigate to `Settings -> SLA Settings` to define time-to-triage thresholds (e.g., Critical alerts must be acknowledged within 15 minutes). The system will automatically tag alerts that breach these rules.
